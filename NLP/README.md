# NLP

This folder contains notes and notebooks for Natural Language Processing.

## Notebook

- `NLP_All_Models_Workflow_Revision.ipynb` - an end-to-end NLP workflow covering text loading, cleaning, representation, model training, prediction, evaluation, and improvement.

## Workflow

```text
Load
  -> Explore and clean text
  -> Split data
  -> Represent text
  -> Train model
  -> Predict
  -> Evaluate
  -> Improve
```

Install the shared dependencies from the repository root before running the
notebook:

```powershell
pip install -r requirements.txt
```
